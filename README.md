# Customer-Sales-Behavior-Frequency
This project demonstrates an end-to-end data analytics workflow using Python, PostgreSQL, SQL, and Power BI. The objective was to extract insights from raw data through data cleaning, exploratory data analysis (EDA), SQL querying, and dashboard visualization.
## The project covers:
 - Loading and processing datasets using Python
 -  Performing Exploratory Data Analysis (EDA)
 - Cleaning and transforming data
 - Running SQL queries on PostgreSQL
 - Building interactive Power BI dashboards
 - Creating a final analytical report
### Tech Stack
- Python – Data processing and analysis
- Pandas & NumPy – Data manipulation
- Matplotlib & Seaborn – Data visualization
- PostgreSQL – Database management and SQL querying
- Power BI – Dashboard creation and business insights
